# 专注工作台 Oil UI 润色记录

## 设计北极星

让用户一眼知道“现在正在做什么”，然后顺手完成下一步。当前任务和计时器是唯一主焦点；计划、记录、待确认和设置都提供上下文，不与主焦点竞争。

## 这轮调整

- 保留暖白、墨色、低饱和灰和单一暖金体系。
- 暖金只用于当前任务、计时器和必要的进度提示。
- 使用连续内容面和细分隔线减少卡片竞争。
- 统一按钮、导航、任务行和表面层级的过渡与按下反馈。
- 保留四个静态视图：今天、计划、回顾、设置与备份。
- 静态预览中的真实业务动作使用提示反馈，不伪装成已连接数据。

## 证据

- 桌面视口：1440×900。
- 手机视口：390×844。
- Oil UI 截图检查：无控制台错误、横向溢出或图片加载失败。
- 主要检查状态：默认今日工作台、切换回顾后返回今天。
