# Unslop 审查与方向

## 审查到的迹象

- `focus-workbench.html` 的 `.eyebrow` 使用全大写英文和宽字距，像模板装饰；改为中文上下文标签。
- 侧栏使用 `◫`、`□`、`◔`、`⚙` 字符混合作为图标，风格和尺寸不统一；改为同一套 CSS 线性图标。
- 顶部“◷ 记用时”、计时“Ⅱ 暂停”、设置“↓ / ↻”把符号和文字混在按钮里；保留文字动作，去掉无助于识别的符号。
- “我的用时 3 条记录 →”使用装饰性箭头；改为具体的“查看 3 条记录”。
- “把注意力留给正在进行的事。”是短说明，带句号；改为无句号的自然界面文案。
- 静态预览中的动作已通过提示反馈，不伪装成真实保存；继续保留这一边界。
- 页面没有渐变、发光、彩色阴影、徽章堆叠或虚构营销数字，这些方向保留。

## 五行方向

- 产品：Lubi 帮助个人按天安排任务、记录实际投入并回看时间使用。
- 性格：安静、准确、带一点纸张和时间账本的温度。
- 世界：桌面上的时间账本，墨水、细线和一天的分段。
- 时刻：当前任务的暖金计时、回顾页面的一条投入趋势线。
- 签名：当前任务左侧的一条暖金线，表示时间正在这里发生。

## 处理范围

这是轻度润色：只修审查到的文案、图标、类型和细节，不改页面结构、功能顺序或产品数据。最终仍是独立静态预览页。
