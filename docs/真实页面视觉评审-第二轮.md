# 真实页面视觉评审 · 第二轮

日期：2026-11-07

对象：Lubi Web 的真实渲染页面（Vite 开发页与生产构建），不是 `.draw-ui` 的静态预览。真实开发库当前为空，内容态使用隔离的合成演示库（`test/support.mjs` 的 `seed`），没有读写任何真实任务或日记。空库的真实页面也单独复核。

证据目录：`.oil-ui/review-round-2/`

- `shots/`：真实空库首轮截图（浅色登录、今天、计划、回顾）
- `seeded/`：修改前的合成内容态（桌面、窄屏、深色）
- `after/`、`verify/`：修改后的合成内容态与交互探针
- `live-after/`：修改后的真实开发页（空库）截图
- `contrast-audit.json`：可见文字对比度审计结果
- `plugin-test.log`、`plugin-test-baseline.log`：插件测试与干净基线对照

## 方法

1. 在 1440×900 与 390×844 两个视口，浅色与深色两种主题下，检查今天、计划（日历／甘特／列表）、回顾、设置、新建任务、命令面板和计时。
2. 对比度审计遍历所有可见文字，按 WCAG 2.1 相对亮度计算文字与最近不透明背景的比值；普通文字门槛 4.5:1，大字号 3:1。审计覆盖今天、回顾、设置、甘特四个场景 × 两套主题。
3. 动效用 `getAnimations()`、`getComputedStyle(...).animationName` 和伪元素样式验证，不只看截图。
4. 回归运行 `npm run build`、`npm run test:layout`、`npm run test:ui-review`；`npm run test:plugin` 与干净 HEAD 做同条件对照，区分本轮引入与迁移既有失败。

## 结论

这一轮找到并修复了两个高影响问题：深色主题几乎不可读，以及今天页的主焦点“当前计时”被记录列表推到首屏之外。其余是噪声、窄屏布局、信息缺口和动效问题。

对比度审计从深色场景 1.01–1.78:1 的不可读，降到 8 个场景全部 0 条低于门槛；网络验收测试全部通过。

## 修复清单

### 1. 深色主题变量断层（严重）

修改前：`seeded/today-dark-1440.png`、`seeded/review-week-dark-1440.png`、`seeded/plan-gantt-dark-1440.png`

`ui-refinement.css` 把浅色别名写死在 `.lubi-root` 上，覆盖了 dark token。页面底色变深，但任务标题仍是墨色、控件仍是浅底白字，多个文字对比度只有 1.01–1.78:1。

处理：在 `ui-refinement.css` 增加深色对应层，把 `--background-primary`、`--text-normal`、`--lubi-card-bg` 等别名重新绑定到 dark token；单独修正侧栏选中、个人用时条目、任务悬停、计时金色、进度条和设置弹窗的浅色硬编码。

修改后：`after/today-dark-1440.png`、`after/review-week-dark-1440.png`、`after/plan-gantt-dark-1440.png`、`verify/new-task-dark-1440.png`、`verify/command-dark-1440.png`

### 2. 今天页计时器被记录列表压到首屏之外（高）

修改前：`seeded/today-light-1440.png` 的右侧从上到下是“我的用时 → 当前计时”。计时是今天页的主焦点，却要滚过六条记录才能看到。

处理：`renderPersonalTime` 在 `lubi-focus-side` 中使用追加而不是前插，保留其他布局原有的“我的用时在前”行为。

修改后：`verify/today-light-live-1440.png`，当前计时在右栏首位，金色左线、金色计时和“计时中”小圆点都在首屏。

### 3. 每行重复的“记用时”按钮（中）

修改前：`seeded/today-light-1440.png` 每行一个描边按钮，六行形成一排同权重控件，压过任务标题。

处理：静止态只保留文字动作，行悬停、键盘聚焦或触摸指针时才显示边框。选择器提高了优先级，避免被通用 `.lubi-btn` 形状覆盖。

修改后：`after/today-light-1440.png`（静止）与 `after/today-light-hover-1440.png`（悬停第一行）。

### 4. 窄屏主按钮是空黑块（中）

修改前：`seeded/today-light-390.png`，主操作文字被上游窄屏规则隐藏，但 Web 覆盖层仍让它 `flex: 1`，留下约 113px 的空黑按钮。

处理：窄屏下固定为 40×32 的方形主按钮，和“记用时”“更多”保持同一行节奏。

修改后：`after/today-light-390.png`、`live-after/today-light-390.png`。

### 5. 窄屏指标值断行（中）

修改前：`seeded/today-light-390.png` 的“11.2h”断成“11.”和“2h”。

处理：指标值禁止换行，并在窄屏降低字号；四个摘要保持两列。

修改后：`verify/today-light-390.png`。

### 6. 窄屏回顾看不到时间范围（中）

修改前：`seeded/review-week-light-390.png` 只有“周 / 月 / 年”和左右箭头，顶栏的日期范围在窄屏被隐藏，用户不知道翻的是哪一周。

处理：窄屏下把工具条里原本给读屏用的范围标签显示出来，放在两个箭头之间。

修改后：`verify/review-week-light-390.png`，显示“10/12 – 10/18”。

### 7. 计划头部重复日期（低）

修改前：`seeded/plan-gantt-light-1440.png` 同时出现完整日期“2026-10-18”和导航标签“10/18 周日”，窄屏上再占一行。

处理：隐藏重复的 `.lubi-schedule-range`，保留导航标签；元素仍在 DOM 中，现有测试和辅助技术仍能读取。

修改后：`after/plan-gantt-light-1440.png`、`live-after/plan-calendar-light-1440.png`。

### 8. 辅助文字与金色文本的对比度（中，可访问性）

修改前：浅色辅助文字 #73777b 在画布上 4.14:1，在表面卡片上 4.32:1；“查看”链接 3.79:1；任务标题悬停金色 2.43:1。

处理：辅助色改为 #686c70（画布 4.65:1，卡片 4.86:1），金色文字改为 #8e6424（4.82:1）；深色沿用 dark token。金色仍只用于当前进行中、当前选中和时间焦点，不做大面积装饰。

修改后：`contrast-audit.json` 的 8 个场景全部为 0 条低对比。

### 9. 侧栏切换后标题与选中态不一致（中）

修改前：`seeded/plan-gantt-light-1440.png` 标题是“计划”，侧栏却高亮“今天”；从今天页点“计划”没有反应，因为 `setTab("tasks")` 在已经处于计划页时直接返回。

处理：`view.ts` 增加 `openToday()` / `openPlan()`；今天页的选中条件与页面标题使用同一组状态（列表 + 日 + 今天）。从今天点“计划”切到周计划；从任意视图点“今天”回到列表日视图。

验证：`probe-nav.mjs` 输出依次为 今天/计划/今天/计划/今天/回顾/今天，标题、日历视图、日周月选中态和侧栏高亮一致。

### 10. 登录页英文全大写眉题（低）

修改前：`shots/login-light-1440.png` 的 `LUBI / PRIVATE WORKSPACE`。

处理：改为“Lubi · 私有工作区”，字距回到正常中文界面尺度；浅色与深色都已复核。

修改后：`after/login-light-1440.png`、`after/login-dark-1440.png`。

### 11. 动效缺失（本轮“补充动效”）

修改前：页面切换、弹窗、菜单、通知、登录卡片基本瞬间出现；只有少量控件颜色过渡。

新增的都是短、低频、和状态变化相关的动作：

| 位置 | 动效 | 时长 |
|---|---|---|
| 页面切换（页签、视图、周期、日期） | 4px 上移 + 淡入 | 180ms |
| 弹窗 / 遮罩 | 6px 上移 + 轻微缩放；遮罩淡入 | 180ms / 160ms |
| 菜单 | 3px 下移 + 淡入 | 120ms |
| 通知 | 6px 下移 + 淡入 | 200ms |
| 登录卡片 | 6px 上移 + 淡入 | 260ms |
| 回顾柱状图 | 从底部裁切展开，按列 20ms 错开 | 360ms |
| 实时计时 | “当前计时”后的小金点缓慢呼吸 | 2.4s 循环 |

实现要点：

- 页面切换类只在渲染 key 变化时加，普通数据刷新不重播。
- 柱状图用 `clip-path` + `animation-fill-mode: backwards`，结束后裁切自动消失，不会永久裁掉柱子上方的数值。
- `.menu`、`.web-login-card` 和设置弹窗不在 `.lubi-root` 作用域内，拿不到 `--lubi-ease`；动画回退到显式的 `cubic-bezier(.2,.8,.2,1)`。没有回退时整个 `animation` 简写会失效，这是探针发现的。
- `prefers-reduced-motion: reduce` 下全部关闭；实时计时的呼吸点也不保留。
- 计时圆点用 `:has()` 挂在真实有 `is-live` 的标题上，同时补上卡片金色左线；原来 `.lubi-focus-timer.is-live` 的选择器是死代码。

动效探针结果：页面进入 `lubi-page-enter` 从 running 到 finished；柱状图 `lubi-bars-enter` 启动时为 running；弹窗 `lubi-dialog-enter`、遮罩 `lubi-backdrop-enter`、菜单 `lubi-pop-enter` 均取到；计时点 `lubi-live-pulse`；窄屏主按钮 40px。

## 验证

- `npm run build`：通过。
- `npm run test:layout`：WEB_LAYOUT_PASS 50 scenes。
- `npm run test:ui-review`：PASS 15/15。
- 对比度审计：8 个场景（浅/深 × 今天/回顾/设置/甘特）全部 0 条低于门槛。
- `npm run test:plugin`：12 通过 / 7 失败。把本轮改动 stash 后在干净 HEAD 上运行，7 个失败完全一致（`async-workflow`、`fix-display`、`monochrome`、`planning-interactions`、`projects`、`smoke`、`ui-interactions`），属于迁移后的既有测试落差，不是本轮引入。

## 仍未处理

1. 日视图甘特默认横向停在 00:00，没有跟随当前时间；当天时间轴也不总是把“现在”放在首屏。周日程已经有 `now − 1h` 的滚动逻辑，日甘特还没有。
2. 设置弹窗里 host 操作区与“插件更新”之间有约 56px 的空带，偏松，不构成错误。
3. 深色下回顾柱状图的分类灰阶随 ink 翻转成高亮白柱，可读但偏刺眼；如果希望更柔和，需要为暗色单独分配灰阶。
4. 顶栏“计划”是任务页的总页签，所以在“今天”页仍处于选中态；页面标题是“今天”。侧栏已经能正确区分今天和计划，是否重命名这个总页签由产品决定。
