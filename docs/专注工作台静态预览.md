# 专注工作台静态预览

`/focus-workbench.html` 是独立的视觉设计预览页，用于评审选定的“专注工作台”方向，不属于真实 Lubi 业务入口，也不连接数据库、API 或插件运行时。

预览包含四个静态视图：今日工作台、周计划、本周回顾、设置与备份。页面内的导航、任务勾选、计时暂停和标签切换只用于展示交互方向；涉及新建、记录、导出、恢复和设置保存的操作会显示“静态设计预览，尚未接入真实数据”的提示。

本地查看：

```text
http://127.0.0.1:5173/focus-workbench.html
```

相关文件位于 `apps/web/public/focus-workbench.{html,css,js}`，与现有 `apps/web/src/main.ts` 业务入口隔离。
